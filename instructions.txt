1. PREREQUISITES & SYSTEM REQUIREMENTS
================================================================================
Before running the software, ensure you have the following installed on your
local machine:

- Node.js: Version 18.x or 20.x (Recommended: v20.x LTS)
  Check version: node -v
  Download: https://nodejs.org/

- Package Manager: npm (v9+ or v10+) or pnpm / yarn
  Check version: npm -v

- Git: (Optional, if cloning from a git repository)
  Check version: git -v

- Modern Web Browser: Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari


================================================================================
2. STEP-BY-STEP INSTALLATION & RUN GUIDE
================================================================================

STEP 1: Extract or Clone the Codebase
--------------------------------------------------------------------------------
If you downloaded a ZIP archive:
  Extract the ZIP archive to a folder of your choice (e.g. ~/projects/autovaluate-india).

If cloning via Git:
  git clone <repository-url> autovaluate-india
  cd autovaluate-india

STEP 2: Open Terminal in Project Directory
--------------------------------------------------------------------------------
Open your terminal (macOS/Linux) or PowerShell / Command Prompt (Windows)
and navigate into the root project directory:
  cd autovaluate-india

Verify you see package.json and server.ts:
  ls -la     (macOS/Linux)
  dir        (Windows)

STEP 3: Install Node.js Dependencies
--------------------------------------------------------------------------------
Run the following command to install all frontend and backend dependencies:
  npm install

This installs Express, Vite, React 19, Tailwind CSS v4, Lucide React,
Motion, TSX, and the Google GenAI SDK.

STEP 4: Set Up Environment Variables (Optional)
--------------------------------------------------------------------------------
Copy the sample environment file to create your local .env file:
  cp .env.example .env    (macOS/Linux)
  copy .env.example .env  (Windows)

Open `.env` in any text editor and optionally add your Gemini API key:
  GEMINI_API_KEY="your_api_key_here"

*NOTE: The platform includes a complete deterministic Indian automotive rule
engine, local entity extractor, and smart vision classifier. The application
will function fully offline and keyless! If provided, Gemini 3.8 Flash will
enhance custom photo analysis and zero-shot NLP parsing.*

STEP 5: Launch the Application
--------------------------------------------------------------------------------
Start the full-stack development server:
  npm run dev

The output will display:
  AutoValuate India server running on http://0.0.0.0:3000
  Vite ready in ... ms

STEP 6: Open in Your Browser
--------------------------------------------------------------------------------
Open your browser and navigate to:
  http://localhost:3000

The AutoValuate India dashboard will load immediately.

3. ENVIRONMENT CONFIGURATION (.env)
================================================================================
The following variables can be configured in your `.env` file:

- PORT:
    Port number the server listens on (default: 3000).
    Example: PORT=3000

- GEMINI_API_KEY:
    (Optional) Google Gemini API key used by server-side endpoints for
    multi-modal Vision classification and conversational NLP parsing.
    Get a key from: https://aistudio.google.com/app/apikey

- APP_URL:
    (Optional) Base URL where the app is hosted (default: http://localhost:3000).


================================================================================
4. AVAILABLE SCRIPTS & COMMANDS
================================================================================
Run these commands from the root directory:

- npm run dev
    Starts the full-stack server using TSX (`tsx server.ts`) which boots
    Express and attaches Vite's dev server middleware. Fast reload enabled.

- npm run build
    Compiles the TypeScript code and bundles the frontend production assets
    into the `dist/` folder using Vite.

- npm start
    Runs the production server (`tsx server.ts`).

- npm run lint
    Runs TypeScript type-checking (`tsc --noEmit`) to verify zero syntax or
    typing discrepancies across the codebase.

- npm run clean
    Cleans up the build cache and `dist/` directory.

6. ARCHITECTURE & LOCAL SERVICES
================================================================================
- Frontend: React 19 + TypeScript + Tailwind CSS v4 + Motion + Lucide React
- Backend: Express (Node.js) running via TSX on port 3000
- Valuation Model: Algorithmic valuation engine calibrated on secondary transactions
  (exponential age retention, RTO tax multipliers, SHAP value feature vector)
- Vision & NLP:
  * Primary: Google GenAI SDK (`@google/genai` with `gemini-3.8-flash`)
  * Local Fallback: Smart vehicle classifier, perceptual image extractor,
    and rule-based NLP entity parser
- Storage / Catalogs: Local TypeScript catalogs in `src/data/` for vehicles,
  generations, specs, failure risks, and RTO tax tables.


================================================================================
7. TROUBLESHOOTING & COMMON ISSUES
================================================================================

Issue: Port 3000 already in use
Solution:
  If another process is using port 3000, specify a different port:
  PORT=3001 npm run dev
  Then open http://localhost:3001 in your browser.

Issue: `node_modules` not found or command not found: tsx
Solution:
  Ensure you ran `npm install` inside the project root before running `npm run dev`.

Issue: Node version incompatibility
Solution:
  Make sure you are using Node.js v18 or v20+. Check with `node -v`.
  Use nvm (Node Version Manager) if needed:
  nvm use 20
